## 修复内容

- `src/format.ts`：首页 `all.other` 先用安全累加器汇总原始日模型中明确不属于 Flash / Pro 的总量，再加上 Flash / Pro 自己的其他类别。任一已知分段缺失时，整体合计仍未知，但不再提前丢掉已返回的未知模型量。全部分段安全时，原有日总量剩余差额兼容逻辑仍保留，不会把未知模型量加两次。
- 未知模型的总量缺失、非法或超过 JavaScript 安全整数范围时，其他分段保持未知。明确返回的零保留；缺少原始行、缺少旧版 `groupKey`、缺段且有无法归属的明确额外量时，不从空筛选创造零。日总量仅因溢出成为 null 不会清掉已经安全的 `other=7` 或 `other=0`。

- `src/usage-trust.ts`：检查已返回月槽位的计数及分段和。即使溢出发生在近七日以外，而每日与近七日仍安全，月槽位未知也会使总体可信度降为“部分”。对应原始别名能证明溢出时给出月槽位安全整数原因，否则说明计数缺失；不把问题误报成缺日期，不要求不存在的月槽位出现。
