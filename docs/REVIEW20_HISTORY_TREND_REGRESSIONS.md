## 原始反例与修复契约

生产路径为主面板 → 用量历史 → 每日趋势／全部历史每月趋势，`HistoryPanel` 实际渲染 `HistoryTrend`，并传入当前日期范围的显示口径。

原实现的 `active` 同时代表鼠标悬停和键盘聚焦：键盘焦点停在 A 时，鼠标进入 B 把明细改成 B，鼠标离开又清空明细，而实际焦点仍在 A。

- Hover、focus、pin 分别保存日期，优先级统一为 **固定 > 聚焦 > 悬停**，与首页／详情七日图一致。点击只切换固定状态，不假定浏览器已经产生 focus 或 mouseenter。
- 柱按钮 `mouseleave` 只清除该日期的 hover，图表 `mouseleave` 只清 hover；`blur` 只清除该日期的 focus。迟到的 A 离开事件不能清掉已经进入 B 的状态。
- 每次渲染先用日期从最新数组取得有效记录。数组位移／重排时保持同日期的按钮 key、数值、未知状态和高亮；不能按旧数组索引显示另一天。日期移出时立即回退到下一有效层，并清理失效身份，空数据或日期重新进入都不复活旧状态。
- 左右键按当前数组顺序查找相邻日期，通过按日期保存的 DOM ref 请求焦点；左右边界不循环。只在实际 `onFocus` 发生时更新 focus 状态，不通过按键事件假造已经取得焦点。数据刷新或日期移出不主动把焦点跳到另一日期。
- Escape 保留原有收起行为，清除三层明细状态，但不调用 `blur()` 或 `focus()`；焦点仍留在原按钮。之后新的 focus／mouseenter／点击可重新显示明细。若在边界对同一已聚焦按钮请求焦点而浏览器未产生新 focus 事件，Escape 后的明细仍保持收起，不能伪造一个新聚焦事件。此处只保留图表按钮内的 Escape，不新增图外全局快捷键。
- 保留 Tokens 千分位、金额 2 至 6 位小数、真实零和“未取得（不代表零）”的区分、调用方的完整／短日期规则，以及每日／每月组名称、按钮日期和值的可访问名称、`aria-pressed` 和 `role=status`／polite／atomic 明细区域。

## 组件回归源码

`tests/history-trend-interactions.test.tsx` 由现有 `npm run test:components` runner 注册，提供 18 个待执行用例。legacy／concurrent 两种 React renderer 均包装 StrictMode；该包装不等于真实 StrictEffects、Windows 浏览器事件顺序或 DOM 焦点已经验证。

覆盖范围：

1. 原始反例：focus A → mouseenter B → mouseleave B → 离开图表，始终显示 A；A blur 后才回退到仍有效的 B hover。
2. 固定、聚焦、悬停竞争与独立释放；迟到的离开／失焦不清理新身份；单独合成点击不制造 hover 或 focus。
3. 分别通过 focus／hover／pin 选中日期，跨月数组位移后同日期节点保持；换新数值、未知数据后明细和可访问名称同步更新。
4. 逐层删除固定／聚焦／悬停日期后的回退；空数组、轴标签、旧日期重入不恢复状态，数据更新不请求重新聚焦。
5. Escape 不调用 focus／blur；左右键使用重排／删除后的相邻日期，边界不循环，不截获 Tab／Enter／Space。`.focus()` mock 只记录目标，必须显式送入 focus 事件后明细才改变，因此不会把 mock 请求冒充 DOM 焦点成功。
6. Tokens／费用精度、真实零／未知、跨年自定义日期、默认日／月标签、按钮类型、装饰柱体隐藏和 live region 属性。
7. 真实 `HistoryPanel` 组件配合合成 IPC 返回，沿“Tokens → 费用 → 全部 → Tokens”操作，覆盖每日／每月两图和两指标的原始混合输入反例；选取实际返回的非未知数据柱。不启动应用，不发送平台请求。

这些断言验证组件状态、结构、可访问属性和 ref 请求目标，**不能证明真实 activeElement、Tab 顺序、Enter／Space 的默认点击、WebView2 自动滚入视野、读屏播报、鼠标事件命中或视觉焦点环正确**。

- [ ] **失焦回退**：A 保持焦点时悬停 B，Tab 离开 A 后显示 B；鼠标离开后收起。反向交错执行 hover A／focus B；重复快速跨柱和 Tab／Shift+Tab，旧柱的离开事件不能抹掉当前柱的状态。
