# 第十七轮托盘唤窗尺寸回归

**状态：仅修改源码和新增回归文本，未运行测试、构建或应用。以下均为待执行项目，不是通过记录。Windows 原生窗口及多显示器验收由维护者完成。**

## 修改契约

- 有效位置记录仍优先恢复用户停留的位置；没有记录或记录所在显示器已移除时，仍按托盘图标中心定位，没有图标记录时沿用光标锚点。
- 恢复记录和托盘回退都经过同一个工作区尺寸／位置入口。先按目标显示器的物理工作区缩小超限尺寸，再用该尺寸计算位置，并约束完整矩形。能容纳的尺寸不主动放大。
- 两条路径都以目标显示器的缩放换算 12 个逻辑像素边距，使用排除任务栏的工作区，不使用显示器全屏尺寸。负坐标工作区不被当成无效位置。
- 物理尺寸调整失败时不继续按未生效的新尺寸定位；读取尺寸失败时不再假设窗口为 0×0。显隐和通知事件仍沿用原有容错行为。
- 跨屏定位后读取实际外部尺寸；若原生 DPI 调整改变尺寸，再按同一目标工作区修正一次。该读取和修正仍须 Windows 实测，不以纯几何测试冒充原生行为证据。
- 主窗口当前是无装饰窗口，物理客户区尺寸与外部尺寸一致。若以后增加系统装饰，需重新核对 `set_size` 的客户区和外框尺寸差异。

## 新增源码回归入口

`src-tauri/src/tray_placement_tests.rs` 由 `tray.rs` 的测试模块加载，调用生产使用的 `main_window_geometry`。七项待运行场景覆盖：

2. 无记录所用的托盘定位策略保留正常 356×600 尺寸和既有右下位置。
3. 100%、125%、150%、200% 缩放下，两条路径的尺寸上界一致。
4. 四边任务栏锚点和非零工作区原点。
5. 负坐标工作区、指向已移除显示器的旧托盘锚点。

7. 合成跨屏 DPI 调整后的更大实际尺寸再次被限制。

这些测试只验证几何算法，不创建原生窗口，不证明托盘事件、显示器选择、Windows DPI 消息顺序或原生尺寸调用已经通过验收。

## Windows 待执行矩阵

记录最终候选提交、Windows / WebView2 版本、各显示器分辨率和缩放、任务栏位置，以及唤出后实际窗口的物理外框和目标工作区。每项明确标记 `PASS` / `FAIL` / `NOT RUN` / `BLOCKED`，附截图及测量依据。

- [ ] **原始拔屏反例**：在高分辨率屏幕打开阅读模式并拖动后隐藏到托盘，拔掉该屏或在系统显示设置中停用该屏，确保旧位置不在任何现存显示器。通过托盘点击和菜单“显示主面板”分别唤出。剩余工作区比旧外框小时，窗口必须真实缩小，四边及底部导航完整可见，任务栏不遮挡控件。
- [ ] **DPI 组合**：分别覆盖 200%→100%、100%→200%、150%→125%，并在目标工作区小于旧外框的情况下重复拔屏步骤。等待系统 DPI 调整结束后重新测量，确认没有先缩小后被系统再次放大到区外。
- [ ] **无位置记录**：使用无真实凭据的独立测试配置，不记录窗口位置。启动后分别使用未发生托盘点击的菜单入口和已有托盘图标矩形的入口。窗口大小超限时同样缩小，正常尺寸不被放大；无图标记录时仍按光标所在屏幕选择位置。
- [ ] **配置读取失败**：仅在可丢弃的独立配置副本制造读取失败，再从托盘唤出。位置恢复失败应进入相同的尺寸安全回退，配置错误仍按原流程展示，损坏原件不被窗口恢复逻辑覆盖或重置。
- [ ] **任务栏工作区**：在操作系统支持的顶部、底部、左侧、右侧任务栏配置下验证贴边方向；另测任务栏自动隐藏。尺寸和位置必须以实际工作区为界，不把任务栏保留区域当成可用空间。不要求为此安装修改系统行为的工具。
- [ ] **负坐标与旧锚点**：把剩余显示器放在主屏左侧或上方，重复拔屏。另在被移除屏上留下旧托盘矩形后从菜单唤出。即使旧锚点远离目标区，完整窗口仍应落在当前选择的有效工作区内。
- [ ] **有效记录不回归**：在显示器仍连接时拖动到任意合法位置后隐藏，再通过托盘、快捷键和重复启动入口唤出。尺寸和位置仍能容纳时保持不变，不被强制吸回托盘；记录左上角有效但右下越界时，只做必要的缩小或夹取。
- [ ] **重复使用**：连续隐藏／唤出、切换紧凑／阅读模式、拔屏后重新接屏。确认没有每次唤出继续缩小、闪动或定位漂移，焦点与面板刷新事件仍正常。重新接屏不会无条件放大窗口，用户仍可显式选择阅读模式。
- [ ] **现有门禁**：在最终候选 Windows 工作区执行现有发布门禁及上述新增 Rust 回归，再按 `ACCEPTANCE_1.3.1.md` 进行真实安装与使用验收。纯几何通过、静态阅读或旧提交的记录均不替代本次原生验收。

如果无法查询有效显示器、工作区或原生尺寸，原有显示主流程仍会尝试显示窗口，但不能把这类降级情况记录为“已保证完整矩形可见”。保留实际失败证据并单独报告。
