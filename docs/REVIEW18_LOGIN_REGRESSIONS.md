## 修改契约

- 每个网页登录 generation 有独立的窗口生命周期信号。登录子窗先隐藏创建，注册捕获自身 generation 和信号的原生事件回调，再显示，不按同名窗口或最新会话推测归属。
- `CloseRequested`（X、Alt+F4、系统关闭）和 `Destroyed` 均立即撤销该窗口的提交资格。正在验证的 IPC 与缓存 watcher 共用可取消等待；最终提交仍必须通过会话锁内的生命周期和 generation 检查，不能仅靠 await 后的一次检查。
- 撤销与提交按准入顺序确定结果：关闭信号先到达，旧 Token 不得进入落盘；提交已经通过锁内准入检查，后来发生的关闭不会撤销成功或发出伪取消事件。保存失败而窗口已关闭时，不允许旧会话继续重试。
- 原生事件回调不等待会话锁。建窗仍由会话锁保护，原生回调不依赖建窗与 UI 线程派发的锁序；回调先发布不加会话锁的撤销信号，再由后台收尾状态、广播一次结束事件。取消、清除和状态查询也改为异步命令，避免 UI IPC 回调等会话锁。收尾尚未调度时，提交和等待守卫已经失效，状态查询也显示结束。
- 成功、取消、清除、替换会话和超时均先在锁内确定应关闭的具体旧窗口句柄，再在锁外关闭。旧窗口迟到的关闭／销毁不会撤销新 Web 或 Manual generation，也不会重新查标签而关闭新的同名窗口。
- 手动保存不依赖登录窗口存在。忘记网页登录数据先建立 clearing 屏障，在锁外关旧窗和准备清除配置；准备失败释放屏障，已撤销的旧请求不恢复。真正的浏览数据清理仍等原有完成回执。
- 主面板 X 的隐藏行为、远程登录来源校验及凭据保护不变。

## 新增源码回归入口

`src-tauri/src/login_close_tests.rs` 由 `usage_watcher.rs` 测试模块加载，调用生产 `LoginWindowLifetime`、`SyncSession` 和 `while_current`。共十项待运行测试，覆盖：

2. IPC 和 watcher 共用等待守卫：先挂起验证，再关窗，最后释放迟到响应，结果不得被采纳。
3. 网络始终无响应时，关窗仍结束等待并丢弃旧请求 future，不必等网络超时。
4. 验证完成与 commit 之间关窗，仍拒绝落盘。
5. 旧窗口迟到销毁不取消新网页登录或手动保存，新拥有者可以提交。
6. 持锁建窗／提交期间发布原生撤销信号不会重入会话锁；已经准入的成功提交不转为取消。
7. 成功后程序主动关窗不追加结束／取消事件，也不允许重复提交。
8. 保存失败且窗口已关闭时，旧提交不能重试，显式新会话可继续。
9. 取消、清除及忘记流程容忍旧窗迟到事件；忘记期间仍禁止新同步，清理完成后可重试。
10. **仅 Windows**：关闭后尝试实际凭据写入操作，配置文件字节、API Key、Token 及各 revision 保持原样。

## Windows 待执行矩阵

每项记录最终候选提交、Windows／WebView2 版本和 `PASS` / `FAIL` / `NOT RUN` / `BLOCKED`。使用可丢弃的独立配置；日志、截图和录屏不要包含真实 Token 或 API Key。

- [ ] **IPC 校验在途关闭**：登录子窗回传候选 Token、网络校验未返回时，分别点击 X、按 Alt+F4、通过系统菜单关闭，再让响应返回。主面板结束等待，不出现成功同步，不修改原 Token／修订号，也不由迟到结果重新弹窗。
- [ ] **watcher 校验在途关闭**：让缓存扫描捕获候选并进入校验，在响应前关闭登录子窗。响应成功或始终不返回两种情况都要覆盖；关闭后不可保存缓存 Token，不能等待完整网络超时才恢复操作。
- [ ] **验证结束到提交的边界**：用维护者自己的调试断点控制验证返回后、提交准入前的时序，关闭后再继续。结果必须被拒绝。反向时序中，提交已准入并成功后再关窗，不得显示伪取消或撤销成功结果。
- [ ] **旧窗口迟到销毁**：登录 A 尚未销毁完毕时启动 B；覆盖新网页登录及手动粘贴。A 的 CloseRequested／Destroyed 迟到时，B 保持其状态并可保存；A 的旧 Token 不得覆盖 B。新窗口不能被 A 的主动关窗代码关闭。
- [ ] **程序关窗不重入**：成功捕获、取消、替换会话、清除、忘记、超时分别触发程序关窗。确认不死锁、不重复 ended、不将成功显示为失败。对快速重试反复操作，尤其检查旧窗关闭与新窗创建重叠时 UI 仍响应。
- [ ] **建窗及销毁异常**：覆盖建窗失败、注册后显示失败、仅触发 Destroyed 的关闭路径；失败应结束本轮等待，原 Token 不变，可以显式重试。隐藏创建期间不应留下不可见且仍活跃的旧登录会话。
- [ ] **手动保存与忘记失败**：无登录子窗时手动保存仍能成功。忘记的关窗或配置准备失败后，旧会话保持撤销、clearing 屏障已释放；真正 WebView2 清理在途／超时仍沿用原有屏障，不能提前允许新登录。
