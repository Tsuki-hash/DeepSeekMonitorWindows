## 修改契约

### 详情的小工作区与文本缩放

- 返回主面板按钮仍在固定外层。详情正文移入独立的 `detail-scroll` 区域，外层继续服从当前窗口尺寸；不新增 480px 原生高度下限，也不主动放大窗口。
- 滚动区高度由面板限制，允许纵向滚动，并提供必要时的横向兜底；区域有可读名称和独立 Tab 焦点，加载或错误状态没有图表按钮时仍能通过键盘滚动正文。
- Hero、指标与图表不再因短视口被压扁。图表保留最小可见柱体，正常高度仍填充剩余空间；标题、柱顶数值、日期、明细和长错误可随内容增高。详情明细取消固定高度，其他面板的明细布局不受此规则影响。
- 保留日期按钮、固定／取消固定、Escape、明细 live region、数据状态与同步入口，不以重挂载整图来解决焦点问题。

### 日期身份与交互优先级

- Hover、focus、pin 都保存日期，渲染时从最新 `points` 取得同一日期的当前数据。React 日期 key 保持不变；跨日左移不把旧索引误当成新日期。
- 优先级继续是固定日期 > 聚焦日期 > 悬停日期。取消固定后回到仍有效的聚焦日期，再到悬停日期。
- 日期移出当前数据时，该层即时失效并回退到下一有效层，不短暂显示移位后的另一日期。随后清理旧身份；日期重新进入不能自动恢复之前的固定或预览状态。
- Escape 清空三层状态；移出日期与卸载时清理不再需要的全局 Escape 监听。数据更新仍使用该日期的最新数值及未知状态。
