**本轮仅完成代码修改与静态审阅。新增测试尚未执行，未编译、未运行脚本、未启动应用，也未进行 Windows、NVDA 或 Narrator 验收。下列项目均为维护者待执行步骤，不是通过记录。**

## 改动与来源边界

- 首页继续使用原来的整行原生按钮，不嵌套第二个按钮，不接管 Enter/Space。紧凑读数仍保留；按钮通过 `aria-describedby` 提供该月槽位的完整整数、模型名和打开详情的说明。描述使用当前数据，不依赖鼠标悬浮或 `title`。本月标记增加箭头以提示可进入详情。
- 模型详情的“本月 Tokens”直接显示完整千分位数，不再只显示 K/M/B/T。该卡片加入可 Tab 到达的命名分组；其可访问描述关联当前完整数值与来源说明，焦点环位于卡片内部。无需先激活按日图表。
- 历史的“平台原始月汇总 · 独立来源口径”仍是默认折叠的原生 `details/summary`。展开后，月 Token 单元格直接显示完整数值，表格有标题与列头，单元格的可访问名称包含来源月份、原始模型名和完整月值。
- 上述三处分别读取原来的 `models[].totalTokens` 或 `rawModels[].totalTokens`。不借用七日图表、已返回日记录小计或费用推算月 Token。历史范围、原始模型筛选、请求/缓存、分页和导出逻辑未改变。
- 单个计数先经过现有安全计数函数：明确 0 保留为 0；缺项、负值、小数、非有限值和超出 JS 安全整数的值显示“未知”。不把无法精确表示的值四舍五入成“精确月数”。费用沿用原来的显示。
- 窄窗与放大时，详情和月来源表的完整数值可换行，不用省略号截断。没有按数值新增焦点循环或自动播报整个历史表。

## Windows 纯键盘验收（待执行）

1. 从首页用 Tab / Shift+Tab 找到模型整行按钮，检查焦点可见。分别用 Enter 和 Space 打开详情，均只打开一次对应模型，不触发页面无关操作。鼠标点击整行仍按原方式进入。
2. 详情无需悬浮即可看到完整月数。Tab 到“平台本月 Tokens 完整数值”分组，检查焦点环完整、数值与模型正确，继续 Tab/Shift+Tab 能离开。数据刷新后，精确数值更新，焦点不被无故移走。
3. 检查返回主面板、再次打开其他模型、快速重复打开/返回、后台刷新后的返回路径。现有视图切换焦点应继续生效，不能出现键盘困住或额外按钮嵌套。
4. 在历史页 Tab 到“平台原始月汇总 · 独立来源口径”，分别用 Enter 和 Space 展开/折叠。展开后直接可见完整月数，不需要悬浮；其他每日明细、范围选择、模型筛选、继续加载和返回操作仍可用。仅展开/折叠不得发起额外查询。
5. 在紧凑 356px、较窄工作区（含 320px 宽）和阅读模式下检查 100%/200% 显示缩放；再开高对比度。完整数字可以换行，但末位不能被省略、横向裁切或盖住费用；焦点可见，纵向滚动可到达全部内容。检查包含第三个“其他”模型的首页布局。
6. 对照样本：月值 123,456,789、七日合计 70、历史已返回日记录 7 应各自保留正确来源标签。未知月值不能因为日记录齐全而显示 70 或 7，0 不能显示“未知”。超界样本应显示“未知”，不展示推测整数。

3. 在历史页确认原生摘要的展开/折叠状态可识别。展开后用该读屏器的表格导航找到月来源表，确认能识别表格标题、列名、月份、原始模型名和每一位月数，不会将此表说成已返回日记录汇总。筛选一个只在月来源存在的模型后再读一次。
