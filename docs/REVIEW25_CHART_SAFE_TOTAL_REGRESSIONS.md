本轮仅作源码静态修改与静态检查。未运行构建、测试、脚本或应用，也未进行 Windows / WebView2 实机验收。下列测试源码已经补齐，但不能据此宣称通过。

## 修复范围

- 新增独立纯模块 `src/usage-counts.ts`，不引用 `history.ts` 或 `format.ts`。每项必须是非负安全整数；每步先比较剩余安全范围再加，超界返回未知，后续零不能恢复确定值。缺失不是零。
- `chartTotal` 与单日的原始模型别名、槽位、分段和都采用相同安全累加。后端槽位 total 为 null 时，前端不得从分段重新生成可信总量。
- 单日、单月都合法不保证月初近七日总量合法。合计超界时首页显示“数据待核对”及安全整数原因，可信状态为“部分”，不显示确定总量或据此生成缓存命中率。
- 超界不改变源日期覆盖。原始记录、模型名、各日安全值、已知分段和真实零保留；缺日期仍采用原有提示。图表已返回但计数未知的日期显示“合计未知”，并保留可用分段，未知分段为“—”。安全兄弟槽位不受影响。
- 异常明细与七日提示出现时图表卡按内容增长，沿用首页外层滚动，避免原 38px 明细高度裁掉原因和分段。正常明细保持紧凑，原有点击固定、键盘关闭和读屏区域不变。
